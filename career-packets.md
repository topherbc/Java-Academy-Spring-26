## Database Administration (DBA)

DBAs manage database systems, ensure performance and availability, handle backups and recovery, optimize queries, and maintain database security.

**MySQL Fundamentals (building on what you learned in class):**
* MySQL Official Documentation: https://dev.mysql.com/doc/
* MySQL performance tuning and optimization: https://dev.mysql.com/doc/refman/8.0/en/optimization.html
* Understanding indexes and query execution plans: https://dev.mysql.com/doc/refman/8.0/en/optimization-indexes.html
* MySQL Workbench advanced features: https://dev.mysql.com/doc/workbench/en/
* ACID properties and transaction management
* Database normalization and design patterns

**DBA Core Responsibilities:**
* https://app.pluralsight.com/paths/skill/sql-server-administration
* Backup and disaster recovery strategies
* Database replication and high availability
* Database security and user management
* Monitoring and alerting (Prometheus, Grafana, or MySQL Enterprise Monitor)
* Capacity planning and scaling strategies

**Advanced Topics:**
* Understanding different database engines (InnoDB, MyISAM)
* Clustering and load balancing
* Database migration strategies
* Automation with scripts and tools
